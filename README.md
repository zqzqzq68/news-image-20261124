A program that sums up Tuesday 24 November 2026's world news in one image.
It renders a newspaper front page — masthead, lead story, six more stories,
and a markets bar chart — as a 1024x1024 PNG, using only the Python 3
standard library. No network, no third-party packages: two runs write
identical bytes.

The day in the picture: Nvidia reinstates Jensen Huang after Trump
intervenes and markets roar; NATO warns over a possible Russian nuclear
weapon in orbit; the ICJ rules Myanmar committed genocide against the
Rohingya; the UN climate summit ends without a deal; Gaza strikes kill
six; Ebola teams are trapped by fighting in DR Congo; the US loses its
measles-free status; a quake shakes Nepal.

## Run it

```sh
python3 main.py
```

Writes `/output/entry.png` (1024x1024 PNG, well under 1 MiB).
